# NUHW Steward Suite - Direct Actions

Lightweight tracking for organizing activity that isn't a grievance or a
Weingarten meeting: informational pickets, rallies, petition drives,
button days, know-your-rights trainings, press actions.

One model, `nuhw.direct_action` - name, type, date, which unit(s) it
targeted, the organizing steward, participants, a plain planned/completed/
cancelled state, and notes. No deadline or procedural logic here (unlike
grievances) since direct actions aren't governed by the CBA.
